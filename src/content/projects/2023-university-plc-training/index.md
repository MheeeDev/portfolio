## Problem

Engineering students reach their final year knowing control theory but having never configured a
PLC, drawn an HMI screen or tuned a loop on real equipment. The university wanted short, hands-on
courses that would close that gap before they started work.

## My role & scope

I worked on the courses while at the system integrator: preparing the trainer kits, the course
material and the hands-on exercises, and helping run the sessions in the lab.

Six courses:

1. PLC ladder programming
2. Siemens TIA Portal V17
3. HMI with the SIMATIC KTP700
4. Process pressure control
5. Modern manufacturing skills
6. Cloud IoT

## Approach

### Hardware for every student

Each student works on a bench trainer — an S7-1200 PLC with a KTP700 panel, push buttons and lamps
— so every exercise ends with something that actually switches.

### A real loop for process control

The pressure-control course runs on a process rig with an air supply, a control valve, a pressure
transmitter and a PID controller in the PLC. Students see what a badly tuned loop does to a real
pressure, not just to a simulated curve.

### Finish with data leaving the PLC

The last course takes PLC data to the cloud, so students see the whole chain from a sensor to a
dashboard.

## Delivery

- Trainer kits and the pressure rig prepared and tested before each course
- Course material and exercises for each of the six topics
- Hands-on sessions in the university's automation lab

## Result

- Students configured PLCs, built HMI screens and tuned a loop on real hardware
- A course set the university could run again with the same kits
- The start of the education work that continued in 2025 and 2026
